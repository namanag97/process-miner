# Demo CLAUDE.md

## Overview
Demo scripts and sample data for showcasing PM4Py capabilities and platform features.

## Key Files

### Insurance_claims_event_log.csv
Large sample event log (32MB) from insurance claims process. Used for:
- Performance testing
- Demo presentations
- Benchmarking algorithms

### pm4py-capabilities.py
Comprehensive script demonstrating PM4Py analysis capabilities:
- Process discovery algorithms
- Conformance checking
- Performance analytics
- Visualization generation

### pm4py_analysis_results.json
Pre-computed analysis results from the sample event log.

## Running Demos

```bash
cd demo
source venv/bin/activate
python pm4py-capabilities.py
```

## Sample Data

The demo includes a virtual environment (`venv/`) with PM4Py installed for standalone execution.

## Usage

- Use for customer demos
- Reference for PM4Py integration patterns
- Benchmark new algorithms against sample data
