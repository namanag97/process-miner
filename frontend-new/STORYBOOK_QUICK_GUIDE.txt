================================================================================
                   STORYBOOK QUICK GUIDE - BUILD UI FAST
================================================================================

START STORYBOOK
───────────────
cd frontend-new && npm run storybook
→ Opens at http://localhost:6006

CREATE A NEW STORY (4 Steps)
────────────────────────────
1. Create file: ComponentName.stories.tsx (next to your component)

2. Paste this template:
   ─────────────────────────────────────────────────────────────────
   import type { Meta, StoryObj } from '@storybook/react';
   import { YourComponent } from './YourComponent';

   const meta: Meta<typeof YourComponent> = {
     title: 'Category/YourComponent',  // e.g., 'Design System/Button'
     component: YourComponent,
     tags: ['autodocs'],               // Auto-generates docs
   };
   export default meta;
   type Story = StoryObj<typeof YourComponent>;

   export const Default: Story = {
     args: {
       // Your component props here
       label: 'Click me',
       variant: 'primary',
     },
   };
   ─────────────────────────────────────────────────────────────────

3. Add more variants:
   export const Loading: Story = { args: { label: 'Loading', loading: true } };
   export const Disabled: Story = { args: { label: 'Disabled', disabled: true } };

4. Save → Storybook auto-refreshes

RAPID UI WORKFLOW
─────────────────
1. Design in isolation    → Build component in Storybook first
2. Add story variants     → Cover all states (hover, loading, error, empty)
3. Use Controls panel     → Tweak props live without code changes
4. Copy to app            → Import finished component into pages

KEY SHORTCUTS
─────────────
Ctrl+K        → Quick search components
S             → Toggle sidebar
A             → Toggle addons panel
D             → Toggle docs mode
F             → Toggle fullscreen

CONTROLS PANEL TRICKS
─────────────────────
• Click any prop in Controls → Modify live
• Object props → Expand to edit nested values
• Actions tab → See logged events (onClick, onChange)

STORY DECORATORS (Wrap components)
──────────────────────────────────
decorators: [
  (Story) => (
    <div style={{ padding: 20, background: '#f5f5f5' }}>
      <Story />
    </div>
  ),
],

COMMON LAYOUTS
──────────────
parameters: { layout: 'centered' }   // Center in canvas
parameters: { layout: 'fullscreen' } // Edge-to-edge
parameters: { layout: 'padded' }     // Default padding

TESTING IN STORYBOOK
────────────────────
Add play function for interaction tests:

export const Clickable: Story = {
  args: { label: 'Submit' },
  play: async ({ canvasElement }) => {
    const canvas = within(canvasElement);
    await userEvent.click(canvas.getByRole('button'));
  },
};

BUILD FOR PRODUCTION
────────────────────
npm run build-storybook
→ Creates static site in storybook-static/
