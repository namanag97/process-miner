# Analysis Domain

## Responsibilities
- Statistics and metadata
- Process discovery (Alpha, Inductive, etc.)
- Conformance checking
- Performance analytics
- Visualization (DFG, Petri nets)
- Predictions (ML)
- Organizational mining
- Simulation
