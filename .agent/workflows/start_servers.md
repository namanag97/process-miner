---
description: Start the Frontend and Backend servers
---
To run the full stack, you will need two terminal windows.

### Terminal 1: Backend

1. Navigate to the backend directory
2. Start the development server

```bash
cd backend
make dev
```

The backend API will be available at http://localhost:8001/api/v1
The API documentation will be at http://localhost:8001/docs

### Terminal 2: Frontend

1. Navigate to the frontend directory
2. Start the development server

```bash
cd frontend-new
npm start
```

The frontend will be available at http://localhost:4200
