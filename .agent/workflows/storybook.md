---
description: Start Storybook for component development and documentation
---
Launch Storybook to develop and document UI components in isolation.

### Start Storybook dev server
// turbo
```bash
cd frontend-new && npm run storybook
```

Storybook will be available at http://localhost:6006

### Build static Storybook
```bash
cd frontend-new && npm run build-storybook
```

> **Tip**: Use Storybook to develop components in isolation before integrating them into pages.
