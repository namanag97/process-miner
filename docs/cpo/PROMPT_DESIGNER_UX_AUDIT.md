# DESIGNER TASK: UX Audit — ATLAS Process Mining

## Your Mission

Evaluate the user experience of ATLAS across all core flows. Identify UX problems, missing affordances, and opportunities for improvement.

---

## UX Audit Checklist

### 1. Navigation & Information Architecture

- [ ] Is the app structure clear? (Where am I? Where can I go?)
- [ ] Are navigation labels understandable?
- [ ] Is there a clear hierarchy (Workspace → Project → Log → Explorer)?
- [ ] Can user easily find Upload?
- [ ] Can user easily find Discovery/Explore?
- [ ] Is there breadcrumb navigation?

### 2. Onboarding & First-Run Experience

- [ ] Does new user know what to do first?
- [ ] Is there a sample dataset available?
- [ ] Are there empty state messages guiding next action?
- [ ] Is there any onboarding tour/walkthrough?

### 3. Form & Input UX

- [ ] Are form labels clear?
- [ ] Is validation immediate and helpful?
- [ ] Are required fields marked?
- [ ] Do dropdowns have sensible defaults?
- [ ] Are error messages actionable?

### 4. Loading & Feedback States

- [ ] Are loading states visible?
- [ ] Is there progress indication for long operations?
- [ ] Do success actions have confirmation?
- [ ] Are errors clearly communicated?

### 5. Process Explorer UX

- [ ] Is the graph readable at default zoom?
- [ ] Are nodes labeled clearly?
- [ ] Is there a legend explaining the visualization?
- [ ] Can user easily identify start/end?
- [ ] Are interaction affordances clear (clickable nodes)?
- [ ] Is the variant list understandable?

### 6. Accessibility Basics

- [ ] Is text readable (size, contrast)?
- [ ] Do buttons look clickable?
- [ ] Is focus state visible?
- [ ] Can keyboard navigate?
